Установка
1.Установите Ollama на ПК,который используете,как сервер
2.Сделайте порты Ollama(чаще всего 11434) доступными
3.На вашем микрокомпьюетере(в моем случае RPI Zero 2W) склонируйте данный репозиторий
4.Запустите скрипт main.py при помощи python /путь/до/скрипта/main.py
В случае,Если у вас не установлены библиотеки,используйте pip install -r /путь/до/скрипта/requirements.txt
